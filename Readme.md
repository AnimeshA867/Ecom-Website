# Ecom Website

This is a basic e-commerce website template using Next.js and MongoDB.

## Getting Started

### Prerequisites

- Node.js (https://nodejs.org/)
- MongoDB (https://www.mongodb.com/)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/diwaslamichhane/Ecom-Website.git
cd Ecom-Website
```

2. Install dependencies:

```bash
npm install
```

3. Create a `.env.local` file in the root of the project and add your MongoDB URI:

```
MONGODB_URI=your_mongodb_uri
```

### Running the Application

To run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

To build the application for production:

```bash
npm run build
```

To start the production server:

```bash
npm start
```
